# まねっこあそび アプリ 🌟（完全安定・改訂版）
**知的障害特別支援学校 小学部 国語科 向け**

---

## 🚨 写真が反映されなかった原因と、今回の修正点

### 原因の究明
1. **Windows ファイアウォールによる通信遮断**:
   Windowsのセキュリティ設定により、ローカルPC（8000番ポート）へのiPadからのアクセスがブロックされていました。そのため、iPadからローカルサーバーに通信が届かず、写真が相手チームに送られない状態となっていました。
2. **3枚撮影しないと送信できない制約**:
   3枚すべてのスロットを撮らないと送信ボタンが押せなかったため、授業の進度によっては途中で止まってしまう原因となっていました。
3. **送信完了画面の不足**:
   送信ボタンを押したあと、相手チームの待機状態が児童に視覚的に分かりにくかった点がありました。

### 今回の修正・改善内容
- 🟢 **クラウドリアルタイム同期（MQTT over WebSocket）を標準搭載**:
  学校のファイアウォールやローカルWi-Fi制限を完全回避し、一般的なWeb閲覧（HTTPS/WSS）通信を通して、iPad同士や電子黒板が**設定不要・完全リアルタイム**で写真・名前を同期します。
- 🟢 **1枚からでも送信可能に緩和**:
  授業の残り時間や児童のペースに合わせて、**1枚でも2枚でも3枚でも**送信できるようになりました。
- 🟢 **送信完了・待機画面の明確化**:
  赤チームが送信すると「✅ あおチームに しゃしんを おくったよ！ まっててね」と画面がはっきり切り替わります。
- 🟢 **「🛠 せんせい おたすけ操作」ボタンを新設**:
  電子黒板画面の右下に先生用のおたすけボタンを用意しました。万が一児童のiPad操作に手間取っても、**「サンプル写真をセットして即送信」「強制的に発表へ進む」**を先生の手元から1秒で実行でき、**授業を絶対に止めません**。

## 📖 授業での使い方・進行フロー

### 準備（1分で完了）
1. 電子黒板または先生のPCでアプリを開きます：
   👉 **http://localhost:8000**
2. 画面右上の **「QRコード」ボタン** を押して、電子黒板にQRコードを大きく映します。
3. 児童のiPadカメラでQRコードを読み取れば、すぐに全員のiPadでアプリが開きます！

---

### 授業の流れ（3ステップ）

```text
【ステップ①：さつえい】
あかチームのiPadで「ポーズをとる」➔ カメラで撮影（1〜3枚）➔「あおチームにおくる」をタッチ！
　　↓（自動で即時反映・ピンポーン♪）
【ステップ②：なまえつけ】
あおチームのiPadに写真が自動で届く ➔ ひらがなキーボードや「おたすけことば」で名前を入力 ➔「できた！おくる」をタッチ！
　　↓（自動で即時反映）
【ステップ③：まねっこ発表】
電子黒板で「第1問」を表示 ➔「オープン！」で名前を発表 ➔「まねっこ！」でカウントダウン（3・2・1）➔ 全員でまねっこ！
　　↓
【こうたい！】
下の「こうたい！」ボタンを押すと、役割が交代して第2回戦がスタート！
```

## 🛡️ 授業を絶対に止めない「あんしん設計」

1. **先生おたすけ操作（画面下の「🛠 せんせい おたすけ操作」）**:
   - 「時間がなくなってきた」「児童の撮影がうまく進まない」というときは、先生画面から **「サンプル写真をセットして送る」** を押せば、かわいいポーズイラストが即座に青チームへ送られます。
   - 「強制的に発表へ進む」を押せば、いつでも発表・まねっこを開始できます。
2. **万が一のオフライン（Wi-Fi不通）でも動く「1台まわしモード」**:
   インターネットが途切れても、1台のiPadを赤チーム→青チームと手渡しして進めることができます。
3. **おたすけことばチップ**:
   キーボード入力が難しい児童でも、「じゃんぷ」「あるく」「ねこ」「ロボット」などの言葉をタップするだけで入力できます。
