# まねっこあそび アプリ 🌟
**知的障害特別支援学校 小学部 国語科 向け**

一人1台のiPadと電子黒板（大型モニター）を活用して、身体の動きを写真に撮り、ひらがなで名前を付け、みんなで楽しく「まねっこ」をする協同学習アプリです。

---

## 🌟 アプリの特徴

1. **特別支援学校小学部に最適化されたUI/UX**
   - すべて「ひらがな表記」、大きくて見やすい丸ゴシックフォント。
   - iPad標準キーボードに対応した特大テキスト入力欄。
   - 文字入力が苦手な児童でもタップで入れられる「おたすけことば（じゃんぷ、ねこ、ロボット等）」チップ。
   - カウントダウン（3・2・1）や「ピンポーン」「ファンファーレ」など楽しい効果音と自動音声読み上げ。

2. **スムーズな授業3ステップ進行**
   - **① さつえいタイム**: 出題チーム（A班）が3つのポーズを撮影。班員全員のiPadに即時同期。
   - **② なまえつけタイム**: 回答チーム（B班）が写真を見て、どんな動きか名前をひらがなで入力。
   - **③ まねっこ発表タイム**: 電子黒板や全員の画面に「だい1もん！」と順番に提示。「オープン！」で名前を発表し、「まねっこ！」でカウントダウンとともにみんなで全身を使ってまねっこ！
   - **④ こうたいボタン**: ワンタップで役割を交代して第2ラウンドへ移行。

3. **配線・インストール不要＆QRコード一発接続**
   - 児童のiPadからアプリのインストールや設定は一切不要。
   - 先生画面に表示されるQRコードをiPadのカメラでかざすだけで即参加できます。
   - ホーム画面に追加すれば、URLバーのない全画面アプリ（PWA）として起動します。

---

## 🚀 使い方・起動方法

### 方法A: 教室のWi-Fiで使う場合（推奨・かんたん）

先生のPCでサーバーを起動し、同一Wi-Fi内のiPadから接続します。

1. **サーバーの起動**:
   ```bash
   py server.py
   ```
2. 画面に表示されたURL、または電子黒板に映した画面の「QRコードボタン」をiPadのカメラで読み取ります。
3. 児童は自分の班（「あかチーム」または「あおチーム」）をタップしてスタート！

### 方法B: GitHub Pagesで使う場合（クラウド公開）

本リポジトリのファイルをそのまま GitHub リポジトリ（例: `manekko-app`）にプッシュし、Settings → Pages で公開するだけで、インターネット経由でどのiPadからもアクセスできます。

## 💡 授業での指導のポイント（指導案メモ）

- **ポーズの工夫**: 「いきものの うごき（うさぎ、へび、とり）」「のりものの うごき（ひこうき、でんしゃ）」「きもちの うごき（うれしい、びっくり）」など、テーマを決めて行うと、より児童がイメージを広げやすくなります。
- **言葉の広がり**: 名前をつけるグループでは、「うさぎ」だけでなく「うさぎ ぴょんぴょん」のように、オノマトペ（擬音語・擬態語）を組み合わせる指導を行うと国語科の豊かな語彙指導につながります。
- **安心の撮り直し**: 写真は「とりなおす」ボタンで何度でもやり直せるため、失敗を恐れず笑顔でポーズをとることができます。
